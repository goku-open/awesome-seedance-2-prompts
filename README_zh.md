Scene 2: 攻防が一気に激しくなる。攻め手は山の斜面を駆け上がり、はしごを石垣や城壁にかけ、兵士たちが城壁を登り始める。城側の守備兵は高所から火矢、投石、槍、叫び声で迎え撃つ。火矢が飛び交い、石が落下し、盾に衝撃が走り、煙と土埃が立ち上がる。攻城兵器は戦場の一部として見えるが、主役ではなく、軍勢全体の中の迫力要素として扱う。俯瞰、横移動、急接近、引きの全景を切り替え、攻めと守りの関係を分かりやすく保つ。

Scene 3: クライマックスでは、城門周辺と城壁上で攻め手と守備側の力が同時にぶつかる。兵士が城壁を登り、守備兵が押し返し、火矢と投石が交錯し、城門付近では衝撃と木片、煙、火花が広がる。巨大攻城兵器を主役にせず、あくまで山城全体の攻防、城壁を登る兵、迎撃する守備兵、城門周辺の混乱を中心に描く。最後は煙と火の向こうにそびえる山城と、まだ続く攻防を感じさせる引きの全景で締める。1〜2秒の短い余韻を残す。

色調は明るくはっきりしたシネマティックな昼光にする。画面全体を灰色や茶色に沈ませず、山城、攻め手、守備兵、火矢、煙、旗の色が明確に分かれるようにする。暖かい自然光、くっきりした輪郭、強めのコントラスト、火矢の鮮やかなオレンジ、旗の赤や白、石垣と木材と鎧の質感差を強調する。曇天すぎる空、低コントラスト、くすんだ灰色、濁った色、全体がぼやけた映像は避ける。
