**镜头语言**
第三人称电影镜头，主要使用中近景和紧凑的全景，穿插少量特写以强调击倒瞬间。镜头整体采用稳定器跟拍+轻微手持冲击感。尽可能少剪辑，优先使用连续摇摄、推进和轨道跟踪镜头，以强化一镜到底的错觉。镜头始终围绕男主角旋转。绝不丢失主枪的视野，绝不丢失主角的身体朝向，绝不让敌人完全遮挡画面。每一个击倒动作都必须清晰可见：谁冲上来，男主角如何接触，如何切换火力，敌人如何倒下，以及镜头最终停留在何处。

**一致性规则**
